# Club logo files

`ClubAvatar` (`components/playground/athlete/club-avatar.tsx`) renders a
club's `logoUrl` when set, falling back to an initials tile otherwise — no
code changes needed to add a real logo, just drop the file in here and set
`logoUrl` on the matching club in `lib/playground/seed-data.ts`.
